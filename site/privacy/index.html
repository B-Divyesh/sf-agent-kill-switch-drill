PRIVACY

Privacy for your stop drills

The CLI keeps your configuration and incident cards on the machine where you run it.

What stays on your device

The command-line tool reads only the config path you provide. It writes an incident card only to the report path you request. Reports contain command IDs and status data. They do not contain command lines, output, environments, or provider secrets.

Optional license

If you choose the support unlock, this site stores the returned license token and its cached result in your browser storage. While online, it sends the token to Sociobot’s license-verification endpoint at most once per day. Sociobot/Dodo handles checkout as merchant of record.

No site tracking

This site does not load analytics, advertising tags, third-party fonts, or third-party scripts. The static site does not set cookies.

Contact

For a purchase privacy question, use the support route shown by Sociobot at checkout.
