PRIVACY

Local by default.

The CLI does not send telemetry, commands, reports, or configuration to us.

What stays on your device

The command-line tool reads only the config path you provide and writes an incident card only to the path you request. Reports contain command IDs and status data, not command lines, output, environments, or provider secrets.

Optional license unlock

If you use the optional support unlock, this site stores the returned license token and its cached verification result in your browser’s local storage. It sends the token to Sociobot’s license-verification endpoint no more than once per day while online. Sociobot/Dodo is the merchant of record for checkout.

No tracking

This site does not use analytics, advertising tags, third-party fonts, or third-party scripts. The static site does not set cookies.

Contact

For privacy questions relating to a purchase, contact the support route provided by Sociobot at checkout.
